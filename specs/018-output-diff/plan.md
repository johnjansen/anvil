# Implementation Plan: Task Output Diffing

**Branch**: `018-output-diff` | **Date**: 2026-02-28 | **Spec**: [spec.md](spec.md)

## Summary

Add run output comparison to the existing `anvil task diff` command. When called with just a task name (or with --run1/--run2 flags), the command compares OutputSummary fields from RunRecords using the existing UnifiedDiff algorithm. Supports configurable context lines, whitespace ignoring, and JSON output.
