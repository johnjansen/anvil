# Implementation Plan: Task Result Passing

**Branch**: `343-task-result-passing` | **Date**: 2026-03-07 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/343-task-result-passing/spec.md`

## Summary

Add native result passing between dependent tasks. Tasks with `capture_output: true` emit `##anvil:result <data>` lines captured by the runner's `statusWriter`. Results are stored in `RunRecord` and passed to dependents via the `ANVIL_DEPENDENCY_RESULTS` environment variable and Go template variables. A new `anvil task results` CLI command provides visibility.

## Technical Context

**Language/Version**: Go 1.24.6
**Primary Dependencies**: `internal/project` (Todo, RunRecord), `internal/daemon` (task execution, dependency checking), `internal/runner` (statusWriter, output scanning), `cmd/anvil` (CLI commands)
**Storage**: JSON files in `.anvil/runs/<task-id>/` (existing RunRecord system)
**Testing**: Go standard `testing` package
**Target Platform**: macOS, Linux (CLI tool)
**Project Type**: CLI tool with background daemon
**Performance Goals**: Result capture adds < 1ms overhead to task completion; result lookup < 100ms
**Constraints**: Result data capped at 1MB per task; backward compatible with existing frontmatter
**Scale/Scope**: Single-user local CLI tool
