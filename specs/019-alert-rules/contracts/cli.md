# CLI Contract: Task Alerting Rules

## anvil alerts

List active alerts.

```
anvil alerts [--task <name>] [--severity <level>] [--json]
```

## anvil alerts ack <id>

Acknowledge an alert.

## anvil alerts history

Show all alerts including acknowledged.

```
anvil alerts history [--task <name>] [--limit N] [--json]
```
